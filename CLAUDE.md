# Engineering Rules

## Branching
- Always create feature branches: feature/<name>

## Testing
- All features must include:
  - Unit tests
  - Edge case tests
  - Integration tests (if applicable)

## Code Quality
- Follow clean architecture
- Avoid duplication
- Use meaningful naming

## Workflow
1. Understand requirement
2. Create branch
3. Write tests
4. Implement
5. Verify tests pass
