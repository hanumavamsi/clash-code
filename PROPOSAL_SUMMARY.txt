📋 THE REQUEST
──────────────
Feature:   Move match questions from inline MatchDetailModal to separate route
Purpose:   Enable realistic practice experience with code editing and testing
Result:    Full-screen replay environment (no timer, no opponent)

✨ THE SOLUTION
───────────────
BEFORE:    Questions shown inline in cramped modal
AFTER:     Dedicated /replay/[matchId]/[questionId] route with full-screen editor

🗺️  ROUTING STRUCTURE
──────────────────────
New Routes:
  /replay/[matchId]/[questionId]     ← Replay single question from match
  /replay/[matchId]                   ← Sequential replay (Phase 5 optional)
  /practice/[questionId]              ← Practice any question (Phase 5)

Preserved Routes (unchanged):
  /                                   Home + History (modified modal only)
  /game/[roomId]                      Live competitive match
  /challenge/[token]                  Challenge mode
  /room/[roomId]                      Pre-game lobby

📡 NEW API ENDPOINTS
──────────────────────
GET  /api/replay/[matchId]/[questionId]
     Returns: Question + user's previous code + match context
     
POST /api/replay/[questionId]/test
     Params:  { code, language }
     Returns: { passed, total, results[], executionTime }

🎯 DESIGN DECISIONS
─────────────────────
1. Questions location        → Separate route (better space, future-proof)
2. Match context            → Minimal sidebar (motivational)
3. Language switching       → Allowed (encourages learning)
4. Code version             → Final submitted (consistent)
5. Solution visibility      → Always available (learning-focused)
6. Record attempts          → No Phase 4 (keep simple, add Phase 5)
7. Question sequence        → One at a time (simpler)
8. Test case limits         → Hide private (maintain some challenge)
9. Back button              → Browser history (natural)
10. Sandbox                 → Separate endpoint (clean separation)
